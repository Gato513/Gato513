# 💫 Sobre Mí:
¡Hola! Soy Antonio Prado, desarrollador Full-Stack MERN y estudiante de Ingeniería en Informática. Tengo conocimientos en Python, JavaScript, React, y experiencia en la creación de soluciones con MySQL, Node.js y Express.js. Me especializo en desarrollar sistemas informaticos estructurados.

Mi objetivo es seguir desarrollando mis habilidades para alcanzar un alto nivel de competencia en el campo del desarrollo de software y contribuir con soluciones innovadoras y de calidad.
